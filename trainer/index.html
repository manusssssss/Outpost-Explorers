SPACE SCIENCE FOR YOUNG EXPLORERS · AGES 7–12

Can you help a crew
live on another world?

Pick a level and a world. Team up as Engineer and Scientist, walk with two crew members, drive the rover, solve field problems, and send your findings home.

Two-player local co-op · one shared screen
Player 1 is the Engineer (W/A/S/D). Player 2 is the Scientist (arrow keys). Use the crew button to switch viewpoint.
Choose a science lead, not a guaranteed water source.
Site rings weigh possible ice or water-shaped minerals alongside light, route safety, and signal access. Orbital clues need ground checks before a crew could count on water. These are training locations, not selected bases.
Where the science comes from

NASA and partner-agency references guide the lessons. The 3D rover terrain is an illustrative training scene, not a mapped landing site. The orbiting Moon uses LROC colour and LOLA elevation maps; NASA Mars Trek is linked for real mapped Mars terrain. Game supplies are simplified teaching units.

Preparing your mission…

Start the local server first

The 3D game cannot start from a file opened by double-clicking. In VS Code, open this folder, choose Terminal → New Terminal, and run:

python -m http.server 8080

If that command is not found, try py -m http.server 8080.

Then open http://localhost:8080 while the terminal stays open.

Your browser couldn’t start the 3D scene.

Try a browser with WebGL enabled, or open the site on a device with 3D graphics support.
